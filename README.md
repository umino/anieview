# AnieView

Windows向け軽量画像ビューワー。

## 特徴

- キーボードショートカットによる快速操作
- 複数ウィンドウ対応（同時に複数画像を表示）
- 画面サイズへのフィット表示・分数リサイズ
- ファイルのドラッグ&ドロップで即時表示
- ソート順（ファイル名 / 更新日時）を設定として永続化

## 対応形式

`.jpg` `.jpeg` `.png` `.webp` `.gif` `.bmp`

## 動作環境

- Windows 10 / 11
- .NET 10

## キーボードショートカット

| キー | 動作 |
|---|---|
| `→` / `Space` | 次の画像 |
| `←` / `Backspace` | 前の画像 |
| `Shift + Space` | 次の画像（Spaceの逆方向） |
| `+` | ズームイン (+10%) |
| `-` | ズームアウト (-10%) |
| `R` | 右回転 (90°) |
| `F` | 画面フィット表示トグル |
| `D` | ウィンドウを複製（同じ画像を別ウィンドウで開く） |
| `B` | すべてのウィンドウを前面に表示 |
| `S` | ソート順切り替え（ファイル名順 / 更新日時順） |
| `2` 〜 `6` | 画面幅の 1/N にリサイズ |
| `Shift + 2` 〜 `Shift + 6` | 画面高さの 1/N にリサイズ |
| `Esc` | ウィンドウを閉じる |
| `Shift + Q` | アプリ終了（全ウィンドウを閉じる） |

## 使い方

1. 画像ファイルを AnieView.exe にドラッグ&ドロップ、またはコマンドライン引数で画像パスを渡す
2. キーボードショートカットで操作

```
AnieView.exe [画像ファイルパス]
```

## アーキテクチャ

クリーンアーキテクチャ（4層構成）を採用。

```
AnieView.Core           # ドメインモデル、インターフェース定義
AnieView.Application    # ユースケース
AnieView.Infrastructure # WPF依存サービス実装（画像読込、ナビゲーション、設定保存）
AnieView.Wpf            # WPF UI（View / ViewModel）
AnieView.Tests          # xUnit ユニットテスト
```
